# Армянская LLM с нуля

Домашнее задание №1: обучить небольшую decoder-only LLM на языке вне мирового топ-50 по числу носителей. Я выбрал армянский: для него есть достаточно текстов для самостоятельного претрейна, а язык и письменность отличаются от русского и английского.

Основная модель — **97 241 856 параметров**, обучена с нуля на ArmWeb, затем продолжила претрейн на смеси **70% ArmWeb / 30% армянской Wikipedia**. BPE-токенизатор тоже обучен с нуля. Предобученные веса не использовались. Финальный checkpoint не проходил SFT.

## Результат

| Модель | ArmWeb test_iid PPL | ArmWeb test_tail PPL | Wikipedia test PPL |
| --- | ---: | ---: | ---: |
| 35M, 1 эпоха | 18.11 | 18.25 | — |
| 97M, 2 эпохи | 13.22 | 13.52 | 23.95 |
| 97M + смесь | **13.16** | **13.44** | **13.07** |

На отложенной Wikipedia perplexity после смеси снизилась примерно на 45.4%. На ArmWeb улучшение небольшое. Checkpoint выбирался по validation, а не по этим тестам. Метрики финального test сохранены в отчёте с округлением вывода ноутбука.

Фактические ответы остаются слабым местом: в zero-shot диагностике из 24 вопросов MC sum вырос с 14 до 17, свободный exact match — с 3 до 6. Ни для одного из 8 фактов модель не дала верный свободный ответ при всех трёх формулировках. Это маленький набор, который многократно просматривался; он не является независимым бенчмарком. В генерациях есть повторы и выдуманные факты.

## Модель и обучение

12 слоёв, ширина 768, 12 голов attention, SwiGLU с hidden dim 2048, pre-RMSNorm, RoPE и общая матрица embedding / output. Контекст — 1024 токена, словарь — 16 000.

Обучение шло на одной H100 80 GB. Использованы AdamW, BF16 autocast при FP32-параметрах, gradient clipping и Flash Attention через PyTorch SDPA. Effective batch — 128 последовательностей: micro batch 32 и накопление 4.

Исходная 97M обработала 2 337 142 784 целевых токена за 2 эпохи. Продолжение на смеси — ещё 655 360 000 токенов, из них 458 752 000 ArmWeb и 196 608 000 Wikipedia. Суммарно — 2 992 502 784 целевых токена.

В репозитории также сохранены эксперименты:

- 35M и 97M с разными бюджетами обучения;
- пилот 222M на 2000 шагах — это не завершённая четырёхэпоховая модель;
- BPE со словарями 8k / 16k / 32k и выборками 100k / 500k;
- подбор micro batch по скорости и памяти;
- контрольное продолжение 97M на новостях и на смеси при равном бюджете 1000 шагов;
- SFT исходной 97M на Aya/Dolly: answer perplexity улучшилась, но свободные ответы в диагностике ухудшились. Эта версия не выбрана финальной.

В сравнении размеров менялось и число обработанных токенов. Поэтому разницу результатов нельзя объяснять только числом параметров. Пропуски в сохранённых логах 97M отмечены на графике; недостающие точки не интерполированы.

## Данные

- [COPA-AI/armweb](https://huggingface.co/datasets/COPA-AI/armweb), revision `804790c6cd783532641b76e27381f92695505ce4`.
- [wikimedia/wikipedia](https://huggingface.co/datasets/wikimedia/wikipedia), subset `20231101.hy`, revision `b04c8d1ceb2f5cd4588862100d08de323dccfbaa`.
- Aya/Dolly использовался только в отдельном эксперименте SFT; загрузчик и фильтры находятся в `download_sft_data.py` и `prepare_sft_data.py`.

После очистки в train ArmWeb осталось 4 102 940 документов, в train Wikipedia — 291 812 статей. Удалялись повторы и иноязычные документы; у Wikipedia также убирались служебные хвосты, извлекались армянские блоки и удалялись точные дубли до разбиения. Просмотренные при настройке фильтров статьи принудительно отнесены к train. Отсутствие близких дублей между корпусами не доказано.

Исходные корпуса скачиваются скриптами из указанных источников. Здесь сохранены код, конфигурации и результаты анализа; при использовании данных действуют условия их источников.

Архив нужно прикрепить к [GitHub Release](https://github.com/AlexandrSurzhanskiy/armenian-llm-hw1/releases); после этого добавить сюда ссылку скачивания.

GitHub блокирует обычные git-файлы больше 100 MiB; для весов подходит Release asset. См. [ограничения файлов GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).

После скачивания распакуй каталог `arm_gpt_97m_cpt_mix` в `LLM_STORAGE_ROOT/artifacts/checkpoints/`. В первой ячейке `inference.ipynb` укажи каталог кода `PROJECT_DIR` и корень `STORAGE_ROOT`. Инструкция загрузки также включена в архив модели.
