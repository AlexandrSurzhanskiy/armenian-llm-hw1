# Оценка и ограничения

## Предсказание текста

Loss — token-weighted cross-entropy по всем next-token targets соответствующего split, включая последний короткий остаток. Perplexity = exp(loss). Checkpoint выбирался по validation до итоговой тестовой оценки.

| Модель | ArmWeb IID | ArmWeb tail | Wikipedia |
| :--- | ---: | ---: | ---: |
| 35M | 18.11 | 18.25 | — |
| 97M | 13.22 | 13.52 | 23.95 |
| 97M + смесь | **13.16** | **13.44** | **13.07** |

В таблице — perplexity. Финальные числа прочитаны из сохранённого вывода ноутбука с округлением loss до 4 знаков, perplexity до 2. Источник и точность каждого значения записаны в [reports/results.json](../reports/results.json).

## Вопросы с переформулировками

8 фактов × 3 формулировки = 24 связанных вопроса. Набор: [facts.json](../configs/evaluation/facts.json). Это многократно просмотренная диагностика; факты могли быть в претрейне. Вопросы не являются 24 независимыми наблюдениями.

- **MC sum:** сумма log-probability токенов кандидата; может предпочитать короткие ответы.
- **MC mean:** среднее по токенам кандидата.
- **Свободный ответ:** greedy-подобная генерация с top-k 1 и exact match после нормализации по заданным aliases.
- **Устойчивость:** все три формулировки одного факта должны быть отвечены верно.

После смеси zero-shot MC sum вырос с **14 до 17 из 24**, свободные ответы — с **3 до 6**. Устойчивость свободных ответов — **0/8**. Правильная первая строка не означает правильность всего продолжения: модель может дальше повторять вопрос или генерировать служебные заголовки.

## Эксперименты

| Эксперимент | Что проверяли | Практический вывод |
| :--- | :--- | :--- |
| 35M / 97M | размер и длительность обучения | 97M лучше, но бюджеты токенов также различаются |
| 222M | пилот до 2000 шагов | обучение идёт; это не завершённая модель |
| BPE 8k / 16k / 32k | сжатие и распределение частот | 16k выбран как компромисс |
| Micro batch | скорость и память на H100 | среди проверенных вариантов быстрее 32 |
| CPT news / mix, 1000 шагов | влияние Wikipedia при равном бюджете | смесь заметно улучшает Wikipedia, немного ухудшает ArmWeb в этой точке |
| Смесь до 5000 шагов | дальнейшая адаптация | улучшение итоговых held-out метрик |
| SFT исходной 97M | обучение только по ответам | answer PPL улучшилась, свободный QA ухудшился; не финальный checkpoint |

Полные сравнения и шесть графиков — в [ноутбуке результатов](../notebooks/03_results.ipynb). В кривой 97M сохранён разрыв там, где промежуточные логи недоступны. Дополнительные точки не придуманы.

## Что результат не доказывает

Модель воспроизводит новостной и энциклопедический стиль, но допускает смысловые противоречия, повторы и выдумывает факты. Автоматическая оценка грамматики армянского языка не проводилась. Модель и эксперименты обучены по одному seed; статистическая устойчивость эффекта не измерялась.
